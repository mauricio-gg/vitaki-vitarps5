What is real

  • Fonts: the app's own Roboto and Roboto Mono (fonts/).
  • Images from the app's assets (assets/): PS5 and PS4 logos, Vita RPS5 logo, category icons, button symbols, controller diagrams.
  • Flat white icons (icons/): Controller pad, Profile and six room icons.
  • All labels, values, defaults and messages come from the app inventory; wording changes are listed in SPEC.md.
  • The app shows no game information. The one image in img/ is a fictional generated scene standing in for the video.

Notes

  • Theme tokens live in tokens-xmb.css (one source of truth, documented in SPEC.md section 1).
  • Glow and blur become baked textures on the Vita; see FEASIBILITY.md.
  • The QR code is illustrative and not scannable. The device frame is a generic handheld.
